# Mucke samples

These 109 WAV sounds come from [Sample Pi](https://github.com/alex-esc/sample-pi) at commit `f14596be37abf227bf77d198c9b0b60d9eb4dca9`. The upstream [credits](SAMPLE_PI_CREDITS.md) identify the samples as CC0 1.0 and list their original creators.

The samples were converted to 48 kHz, 16-bit mono PCM WAV. They play as one-shot sounds at their original pitch. Synth notes and chords use the separate MIDI synthesizer.

Sample paths are relative to the `.mucke` file. For a file at the project root, use `sample: "samples/drums/kick/bd_808.wav"`. For a file in `examples/`, use `sample: "../samples/drums/kick/bd_808.wav"`.
